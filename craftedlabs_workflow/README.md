# CraftedLabs Founder Workflow

A self-contained HTML/CSS/JavaScript planning dashboard for the CraftedLabs digital-product store.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Use the sidebar to navigate between the workflow sections.
4. Tick checkboxes as you complete tasks. Progress is saved in that browser on that device using localStorage.

## Included
- Founder overview and business model
- Build workflow and 30-day roadmap
- Initial product categories and product-quality checklist
- Store pages, technology stack and admin features
- Payment verification and secure download workflow
- Marketing and growth plan
- Launch checklist and first 90-day plan

## Important
This is a planning dashboard, not a functioning online store. It does not process payments, create user accounts, upload products, or deliver files. Those features require a real backend, payment-provider account, server-side webhook verification, private file storage and security testing.

The technology/provider suggestions are planning options. Verify current country eligibility, account-age requirements, fees, payout methods and hosting terms before launch.
